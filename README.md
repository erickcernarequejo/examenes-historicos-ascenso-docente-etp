# Exámenes históricos de Ascenso Docente — EPT

Banco interactivo de exámenes de Ascenso Docente para **Educación para el Trabajo**, organizado por año y forma.

## Exámenes disponibles

### 2019

- Forma 1 — A13-EBRS-31
- Forma 2 — A14-EBRS-32

Cada práctica incluye 60 preguntas, alternativas, clave oficial, recursos visuales, navegación, comprobación inmediata, resultados y guardado local del progreso.

## Uso local

Abre `index.html` directamente en el navegador o inicia un servidor estático, por ejemplo con Live Server.

```text
index.html     Catálogo general
forma1.html    Examen 2019 · Forma 1
forma2.html    Examen 2019 · Forma 2
```

No requiere instalación de dependencias ni proceso de compilación.
